# Rollverse

**v1.1.0** — 3D endless rolling-ball arcade game. Steer the ball, dodge obstacles, grab gems and roll through infinite procedurally generated worlds.

▶ **Play:** https://elchinjabbarli.github.io/rollverse/

Built with TypeScript + Three.js. This public repository contains only the built static site — no tokens, no API keys, no trackers. Source lives in the private dev repository.
